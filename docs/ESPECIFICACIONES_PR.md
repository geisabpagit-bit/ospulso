# Especificaciones de Pull Requests y Revisiones de Código

## 1. Reglas de Contribución y Commit
1. **Sincronización Automática Git**: Al finalizar cambios, ejecutar `git add .`, `git commit` y `git push`.
2. **Mensajes Convencionales**: Usar prefijos `feat:`, `fix:`, `style:`, `docs:`, `refactor:`.
3. **Verificación Previa**: Correr `perl -c <script.pl>` antes de realizar commit.
