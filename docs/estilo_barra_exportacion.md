# Estilo y Configuración de Barra de Exportación DataTables

## 1. Botones de Exportación
Las tablas DataTables integran la barra de herramientas de exportación estandarizada:
- **Excel**: Exportación en formato XLSX con títulos limpios.
- **PDF**: Generación de reportes PDF con tipografía corporativa.
- **Imprimir**: Impresión plana omitiendo elementos de control `.no-print`.
